
# Call Center Performance Analytics Dashboard

## Project Overview
An interactive Microsoft Excel dashboard developed to
analyze call center operations, customer satisfaction,
and representative performance across multiple regions.

## Dashboard Features

- KPI tracking: Total Calls, Amount, Duration,
  Average Rating, and Happy Callers.
- Monthly call trend analysis.
- Representative-wise performance comparison.
- Regional performance analysis.
- Male vs Female caller analysis.
- Customer rating distribution.
- Interactive filters for representative-level analysis.
- Conditional formatting and visual reporting.

## Tools Used
- Microsoft Excel
- Excel Charts
- Interactive Filters / Slicers
- Conditional Formatting
- KPI Reporting

## Project Objective
To transform call center data into an interactive
visual dashboard that makes operational performance
and customer trends easier to understand.
